
## Launchpad 重复图标修复（19:20）

现象：Launchpad 里「卓动悦听」出现多次，点其中一个是跳到源码/废纸篓/旧 dmg 卷。
根因：LaunchServices 把构建产物、废纸篓、历史挂载卷、临时测试目录里的 .app 都注册成应用。
排查时实际挂载卷已无，但注册残留：废纸篓、/Volumes/卓动悦听{,_1,_2,_4}、/private/tmp/zdmusic-app-test.*。

修复：
- `scripts/build.sh`：tauri 出的 .app 立刻移到隐藏 `bundle/.staging/`，注销旧 macos/ 路径；
  DMG 仍从 staging 压。开头补 `unset npm_config_prefix`（否则本环境 nvm 在 set -e 下退出）。
- 新增 `scripts/clean-launchpad.sh` 兜底清理；`src-tauri/.metadata_never_index` + target hidden。
- `docs/tauri-implementation.md` 的 .app 路径改 staging；AGENTS.md 加注意事项。

注意：`lsregister -u -f "/Applications/../Applications/x.app"` 这种写法会把真应用的注册也注销！
清理时必须精确匹配 /Applications 路径；误删后用 `lsregister -R -f /Applications/卓动悦听.app` 恢复。
已卸载卷的 container 记录（/Volumes/... 无 .app 后缀）清不掉但不在 Launchpad 显示，无害。

验证：注册里只剩 /Applications 一条 app；staging 移动逻辑单测通过。
完整构建没跑完——build.sh 原有"清 debug 产物"步骤触发环境的批量删除确认钩子（4929 文件），
非本次改动问题；环境初始化和移动逻辑已分别验证。
