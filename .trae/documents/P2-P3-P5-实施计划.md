# P2 / P3 / P5 实施计划

## Context

P0（设计令牌 + AppShell 三层骨架）与 P1（Library / Queue / Playback 播放内核）已完成并验证通过。当前 `HomeView`、`StageView`、`OverlayLayer` 都是 P0 占位，`PlayerDock` 是 P1 临时控件（带曲库 Sheet）。

本轮把应用从「空骨架」补成可用形态：

- **P2 Home**：首屏有内容（Hero 时钟、今日聆听、继续听、发现条），空队列启动进 Home。
- **P3 舞台**：播放即进入封面粒子舞台，底栏自动隐藏 + 236px 把手唤出。
- **P5 浮层**：Cmd+K 搜索、左边缘队列抽屉、6 组设置抽屉，且都能真实操作队列。

约束：所有颜色/圆角/动效取 `app/styles/tokens.css`；队列浮层必须真实点播/删项/清空/跳到当前曲；暂停不收起底栏；鼠标移把手立即出现；触屏可唤出；dev server 跑在 3978。

## 关键现状（已确认）

- `app/page.tsx` → `AppShell`；`app/components/providers.tsx` 中 `PlayerProvider` 实际挂载新内核 `PlayerRoot`（`app/context/player/index.tsx`）。
- `AppShell` 现有视图切换用 `currentTrack ? "stage" : "home"`，且自动隐藏逻辑只监听 `mousemove`，暂停/触屏/把手不满足要求 → 需重写。
- `PlayerDock` 已有上一首/播放/下一首/进度/循环/随机/音量/淡入淡出，但曲库入口是 Sheet，P5 由队列抽屉替代。
- 队列内核已提供 `replaceQueue / enqueue / addNext / removeItem / clearQueue / setCurrentUid / next / prev / cycleRepeat / toggleShuffle`（`app/context/player/queue.tsx`）。
- 播放内核已提供 `play/pause/seek/stop/setVolume/setRate/setFadeIn/setFadeOut/analyser/vizReady`（`app/context/player/playback.tsx`）。
- 历史 API：`/api/play-history?action=all|recent|frequent`；歌单 API：`GET /api/playlists`；本地搜索可直接过滤 `useLibrary().tracks`；B 站：`/api/bili/search?keyword=`。
- 配置 API：`GET /api/config` 返回 `{ music_dir, env_vars }`；`POST /api/config` 目前**整文件覆盖**（会丢 `theme_id` 等键）→ 本轮改为与旧文件浅合并。
- 封面：曲库 `Track` 无封面；`/api/tracks/metadata` 提供 `coverDataUrl`（按 track id 可查）。舞台/缩略图懒加载一次并缓存。
- `three` 未安装。**不新增依赖**，封面粒子用 Canvas2D 点云实现（同样满足「封面采样 + 节拍位移 + 鼠标视差」，性能更好、无包体风险）。

## 实施顺序

P2 → P5 队列抽屉 → P3 舞台/P层 → P5 搜索与设置 → 收尾联调。原因：队列抽屉会替换 `PlayerDock` 的临时 Sheet；舞台和底栏共享同一套自动隐藏逻辑，先定浮层状态机再改底栏最省返工。

### 舞台动效

- 粒子：封面存在则采样像素点（跳过近黑/透明），无封面用 tint 网格点；每帧读取 `playback.analyser` 的频域数据，低频驱动径向位移，中频驱动亮度；`globalCompositeOperation="lighter"`。
- 节拍镜头：对舞台内容容器做 `scale/translate`（ref 直接改 style，不 setState），幅度随低频能量平滑。
- 只读 `analyser`，不依赖 P1 之外的事件；暂停时粒子静止但保留画面。
- `prefers-reduced-motion` 或 canvas 创建失败：只显示 CSS 渐变封面，不报错。
- 舞台非 active 时停止 `requestAnimationFrame`。

### 底栏（PlayerDock 正式版）

- 结构：`[上一首][播放/暂停][下一首] [标题+进度条+时间] [循环][随机][音量][搜索][队列][设置]`。
- 保留淡入淡出/音量 Popover；移除 P1 曲库 Sheet。
- 尺寸/圆角全部走 `.zd-dock` + tokens，不写死颜色。

### 自动隐藏（满足 4 条硬约束）

AppShell 内改为：

- **仅 `playing` 时**启动 3s 计时；暂停立即显示并取消计时。
- `pointermove`（兼容鼠标/触屏拖动）：显示底栏并把「距底 <160px」视为热区，热区内取消计时。
- 抽屉/底栏 `pointerenter` 取消计时，`pointerleave` 重新计时。
- `pointerdown` / `touchstart` / `keydown` 任意位置：立即显示并重置计时（触屏点任意处可唤出）。
- `zd-handle` 236×28 点击切换；hover 时立即显示（handle 始终可点）。
- 首次进入舞台显示 5s 再开始计时。

### 搜索交互

- `Cmd/Ctrl+K` 或底栏搜索按钮打开；输入框自动聚焦；`Esc` 关闭。
- 本地 tab：对 `useLibrary().tracks` 即时过滤（标题/作者/文件名），展示前 12 条；每条提供 `播放`（`replaceQueue(结果集, {startIndex, play})`）与 `下一首播放`（`addNext`）。
- B 站 tab：500ms 防抖请求 `/api/bili/search?keyword=`；结果展示标题/UP/时长/封面；提供「复制链接」与「在浏览器打开」（当前无独立转换 API，不伪造下载动作）。
- 结果区可键盘上下选择、Enter 播放；搜索框内输入不触发全局播放快捷键（现有 hook 已忽略 INPUT）。

### 设置 6 组

1. **外观**：强调色（青绿 `#00f5D4` / 香槟 `#F4D28A` / 冷蓝 `#9db8cf`，写入 `--zd-accent-home`）、密度（默认/紧凑 → `data-density`）、歌词字号（写 `--zd-text-lyric`，P4 生效）。
2. **播放**：音量、淡入、淡出、倍速（0.75/1/1.25/1.5，`setRate`）、当前循环/随机状态。
3. **曲库**：显示/编辑 `music_dir`、重新扫描（`library.scan()`）、曲目数；保存后提示「需重启生效」。
4. **AI**：`ANTHROPIC_API_KEY / BASE_URL / MODEL`。
5. **集成**：`BILIBILI_COOKIE_SESSDATA / BUVID3`、`ACRCLOUD_ACCESS_KEY / SECRET`。
6. **关于**：版本、许可、快捷键清单（Space/←→/↑↓/M/Cmd+K/Esc）。

保存流程：`GET /api/config` → 合并表单值 → `POST /api/config` → `POST /api/config/reload`；失败就地显示错误，不关抽屉。

## 关键实现决策

1. **不引入 `three`**：Canvas2D 点云足够，避免新依赖与打包体积。
2. **视图切换用会话态**：`hasEnteredStage` 只在「本会话开始播放」时置 true；快照恢复后保持 Home，点「继续听」再进舞台；清空队列回 Home。
3. **浮层互斥**：同一时间只允许一个主浮层；队列抽屉 hover 与 pin 独立于 pin 状态；Esc 先关最上层。
4. **设置保存不覆盖未知键**：改 POST 为浅合并，属必要安全修正。
5. **封面按需加载**：只有舞台/缩略图请求 metadata，Home 用渐变封面，避免首屏被 ID3 解析拖慢。
